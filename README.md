# Dicee

A simple dice rolling application built using Flutter.

## Overview

Dicee is a basic Flutter project designed to demonstrate how to create a user interface for a dice rolling game. It provides a visual representation of dice rolls and can be easily extended or modified to include additional features such as different types of dice, betting, or multiplayer functionality.

## Requirements

- **Flutter SDK**: 3.0.0 or higher
- **Dart SDK**: 2.17.0 or higher
- **Xcode** (for iOS development): 13.0 or higher
- **Android Studio** (for Android development): 4.0 or higher

## Installation

To set up the project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/PartORG/Dicee_Flutter.git
   cd Dicee_Flutter
   ```

2. Install dependencies:
   ```sh
   flutter pub get
   ```

3. For Android, ensure you have the necessary SDKs and tools installed in Android Studio.

4. For iOS, open `ios/Runner.xcworkspace` in Xcode and configure your project settings.

## Usage

To run the project on an emulator or physical device:

1. On macOS/Linux:
   ```sh
   flutter run
   ```

2. On Windows:
   ```sh
   flutter run -d windows
   ```

3. For iOS:
   ```sh
   flutter run -d ios
   ```

4. For Android:
   ```sh
   flutter run -d android
   ```

This will start the Dicee application on your specified device or emulator, allowing you to roll dice and interact with the game interface.

For more detailed information and advanced usage, refer to the [Flutter documentation](https://docs.flutter.dev/).
